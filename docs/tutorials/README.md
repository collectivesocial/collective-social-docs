# Tutorials

**Learning-oriented documentation**

## Purpose

Tutorials are lessons that take the reader by the hand through a series of steps to complete a project of some kind. They are **learning-oriented** and designed to help newcomers get started successfully.

## What Belongs Here

### ✅ Include:
- **Step-by-step instructions** - Clear, numbered steps that guide the learner
- **A complete, working example** - Something the learner can build from start to finish
- **Minimal explanation** - Just enough to understand what's happening, not why
- **Expected outcomes** - What the learner will have at the end
- **Prerequisites** clearly stated
- **Guaranteed success** - Every step should work if followed correctly

### ❌ Don't Include:
- Complex explanations of concepts (save for [Explanation](../explanation/))
- Multiple ways to do things (save for [How-to Guides](../how-to-guides/))
- Complete API documentation (save for [Reference](../reference/))
- Troubleshooting edge cases
- Optional steps or variations

## Writing Guidelines

1. **Start with the end in mind** - Tell learners what they'll build
2. **Be concrete, not abstract** - Use specific examples, not general patterns
3. **Get them doing immediately** - Start with action, not theory
4. **Focus on safety** - The learner should never get stuck or break things
5. **Provide encouragement** - Celebrate progress along the way

## Example Tutorial Topics

- Getting Started: Build Your First Collective Social App
- Create a Simple Feed Reader
- Implement OAuth Login in 10 Minutes
- Build a Post Composer Widget

## Tutorial Structure Template

```markdown
# Tutorial Title

**What you'll build:** Brief description
**Time required:** X minutes
**Prerequisites:** What you need before starting

## What You'll Learn
- Skill 1
- Skill 2
- Skill 3

## Step 1: [Action]
Clear instructions...

## Step 2: [Action]
Clear instructions...

## Summary
What you accomplished and next steps.
```
