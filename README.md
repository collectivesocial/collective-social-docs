# Collective Social Framework Documentation

Welcome to the documentation for the **Collective Social Framework** - a platform for building social applications on the AT Protocol (Bluesky).

## About This Documentation

This documentation follows the [Diátaxis framework](https://diataxis.fr/), which organizes documentation into four distinct types, each serving a different purpose:

- **Tutorials** - Learning-oriented lessons
- **How-to Guides** - Task-oriented directions
- **Reference** - Information-oriented technical descriptions
- **Explanation** - Understanding-oriented discussions

## Documentation Sections

### 📚 [Tutorials](./docs/tutorials/)

Step-by-step lessons to help you learn by building. Start here if you're new to the Collective Social framework.

### 🔧 [How-to Guides](./docs/how-to-guides/)

Practical guides for accomplishing specific tasks and solving real-world problems.

### 📖 [Reference](./docs/reference/)

Technical reference material including API documentation, configuration options, and specifications.

### 💡 [Explanation](./docs/explanation/)

In-depth explanations of concepts, architecture decisions, and the "why" behind the framework.

## About Collective Social

Collective Social is a framework for building decentralized social applications on the AT Protocol, providing OAuth authentication, data management, and real-time firehose integration out of the box.
